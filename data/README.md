# Data files

This directory contains the following fixed JSON subsets used by the project:

```text
harmless.json
harmful_response.json
score34.json
OKTest.json
XSTest_safe.json
PHTest-200.json
or-bench-hard-1k-200.json
AdvBench-200.json
JailbreakBench_harmful.json
```

The first three files construct ProSafePrune activation subspaces. The remaining files are used by the evaluation pipeline.
